# AI Crypto Quant Pro（第一版 v0.1.1，已完成第二輪獨立審查）

加密貨幣（BTC/ETH 永續合約）短線**量化分析 + 模擬交易**系統。繁體中文儀表板、台北時區、USDT 計價。

> ⚠️ **重要聲明**
> - 本系統**不預測未來價格、不保證獲利**，也不是投資建議。
> - **預設且目前只有「模擬交易」。真實下單在 v1 完全沒有實作**，`.env` 設 `LIVE_TRADING_ENABLED=true` 也會被忽略。
> - 所有風控預設值（單筆風險 0.25%、單日損失 1%、槓桿上限 3 倍）、手續費、滑價、資金費率都是**保守的工程測試假設**，請依你的交易所帳戶實際值調整。
> - 目前**沒有任何證據顯示基準策略扣除成本後有正期望值**（見下方「驗證結果」）。

## 3. 從零安裝與啟動

需要 **Python 3.10 以上**（開發環境為 3.12）。

**Windows（命令提示字元）**
```
cd aicq_pro
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
streamlit run app.py
```
**macOS / Linux**
```
cd aicq_pro
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
streamlit run app.py
```
瀏覽器會自動開啟 `http://localhost:8501`。

**驗收自我檢查（建議依序做）**
1. `pytest -q`（或 `python run_tests.py`）→ 應顯示全部通過。
2. `python cli.py backtest --synthetic --timeframe 15m --bars 8000` → 不需網路，確認回測流程可跑。
3. 啟動儀表板，側邊欄選「**測試資料**」→ 檢查每個分頁都能顯示，且頂端有黃色「合成測試資料」警告。
4. 側邊欄改選「**即時行情**」→ 有網路應顯示綠色「行情正常」；斷網應顯示紅色「行情離線」且不產生訊號。

## 4. 操作說明

側邊欄：選資料來源、標的、週期、K 線根數；可開自動重新整理（會暫停數秒後重跑，間隔內畫面不會互動）。

| 分頁 | 內容 |
|---|---|
| 市場總覽 | 各標的最新價、24h 漲跌、市場狀態、方向、資料狀態；帳戶權益、今日損益、持倉數 |
| K線與指標 | K 線＋EMA/VWAP/布林＋成交量＋RSI/ADX；有訊號時畫出進場/止損/止盈線；資料品質檢查結果 |
| 交易訊號 | 方向、依據、證據評分、進場/止損/止盈、風險報酬比（毛/淨）、倉位與保證金、預估成本、強平價、反面證據、不確定性。可按「建立模擬單」 |
| 策略回測 | 訓練/驗證/樣本外、Walk-forward、成本敏感度、分市場狀態表現、被風控擋下的原因、與買入持有比較 |
| 模擬帳戶 | 權益、已實現損益、持倉、資金曲線；按「更新持倉」用最新已收盤 K 線檢查止損/止盈 |
| 交易紀錄 | 每筆模擬交易（含進場原因）、訊號紀錄、風控拒絕事件 |
| 設定與風控 | 調整風控、成本、策略參數（須人工按「套用設定」；系統不會自行放大風險） |
| 說明與狀態 | 功能完成度與限制 |

**訊號輸出的分數**：「獨立證據 N/4 組成立」只是數出成立的證據組數（EMA/ADX/VWAP 視為同一組，布林/RSI 視為同一組，避免重複計票），**不是獲勝機率**；本系統沒有經驗證的機率校準模型。

## 5. 歷史行情下載與驗證

```
python cli.py download --symbol BTC/USDT:USDT --timeframe 15m --days 90   # 需要網路與 ccxt
python cli.py download --symbol BTC/USDT:USDT --timeframe 1h  --days 90   # 高週期（回測的多週期判斷需要）
python cli.py validate --symbol BTC/USDT:USDT --timeframe 15m
python cli.py backtest --symbol BTC/USDT:USDT --timeframe 15m --bars 8000
```
資料檢查項目：缺漏 K 線、重複時間戳、排序、NaN、價格≤0、高低點矛盾、成交量<0、最後一根是否已收盤、資料是否過期（預設超過 2.5 根週期視為過期）。近 200 根內有缺口會**阻擋**產生訊號。
商品代號使用 CCXT 統一格式的永續合約：`BTC/USDT:USDT`、`ETH/USDT:USDT`。

## 6. 回測與風控的設計與假設

**時序（防前視偏差）**：訊號在第 i 根「收盤」產生 → 第 i+1 根「開盤」成交（可再加延遲）→ 之後逐根檢查止損/止盈。1h 高週期趨勢只取「已收盤」的那一根。以測試保證：截斷到第 k 根的資料算出的特徵與訊號，必須與完整資料的前 k 根完全一致。

**成交與成本**：手續費（taker，進出各一次）、滑價（進場與止損市價單的不利方向；**滑價已內含於成交價，報表的「總滑價」只是資訊欄，不會再扣一次**）、資金費（依持倉期間跨過幾次 00/08/16 UTC 結算；回測引擎可傳入真實費率序列，UI/CLI 目前用固定假設）。跳空越過粗估強平價時，以強平價出場並標記 `liquidated`。同一根 K 線同時觸及止損與止盈 → **保守判定先止損**並標記；開盤跳空越過止損 → 以開盤價成交。止盈視為限價單（無滑價、**價格觸及即視為成交，這是偏樂觀的假設**；但手續費仍按 taker 計，部分抵銷）。

**風控閘門（`risk/manager.py`，每筆交易都要通過）**：行情資料正常（含 **1h 高週期資料**也必須正常，否則不產生可執行訊號）；訊號 K 線收盤超過 1 根週期則拒絕模擬成交；單日損失未達上限（以台北日為準；日初權益由已平倉紀錄推導，**程式當天稍晚才啟動也不會漏算先前虧損**；已知限制：跨日未平倉單在午夜前的未實現損益無法還原）；持倉數與總曝險未超限；同商品不得重複持倉（禁止加碼/攤平）；同一訊號不得重複執行（以上三項由**資料庫層原子保證**，多個瀏覽器分頁同時按也不會超限）；策略回撤超限即停用；倉位依「止損距離＋成本」反推（槓桿只影響保證金與強平距離，不影響風險）；名目價值、保證金、止損實際風險分開計算；止損須明顯早於粗估強平價；扣成本後風險報酬比與成本占風險比須達標；最小下單量/最小名目/價格與數量精度；**任何計算例外 → 擋單**。無馬丁格爾、無虧損後加槓桿。

**樣本外驗證**
- **三段式選參**（前 50% 訓練／中 20% 驗證／後 30% 樣本外，之間留空窗）：只在訓練段選參數（需交易數 ≥20 且期望值為正）→ 驗證段把關（交易數 ≥10 且期望值為正）→ 樣本外只對「已凍結且通過驗證」的參數評估一次。沒有參數通過就直接回報「未驗證」，不會硬拿一組去看樣本外。
- 另提供「預設參數三段表現」（未對任何一段調校，只看穩定性）、Walk-forward（只在訓練窗選參數，且訓練期望值必須為正才交易）、參數／時期穩健性表、成本敏感度、分市場狀態表現。
- **統計判定**（`oos_verdict`）：交易數 ≥30、每筆期望值 95% 信賴區間下界 >0、獲利因子 >1、淨報酬 >0、回撤在上限內，才顯示「通過（尚未被否定）」；交易數不足顯示「證據不足」。
- **試驗次數**：每次回測（設定＋資料指紋＋結果）都寫入資料庫並累計；累計 ≥5 次畫面會警告「樣本外已逐漸失去獨立性」。
- 在 60 組**完全沒有優勢**的隨機漫步（零成本）資料上跑整套流程：3 種判定共 180 次，僅 1 次誤報「通過」（任一種通過的比例 1/60）。樣本很小，只說明判定偏保守，不是統計保證。

**Sharpe**：提供「日報酬年化（√365、無風險利率 0，少於 10 天回傳 NaN）」與「每筆交易（非年化）」兩種並標註。

## 7. 錯誤排除

| 現象 | 處理 |
|---|---|
| `ModuleNotFoundError: streamlit/ccxt/plotly` | 確認已啟用虛擬環境並執行 `pip install -r requirements.txt` |
| 畫面顯示「行情離線」 | 檢查網路；部分地區可能無法連線該交易所；可改 `.env` 的 `AICQ_EXCHANGE` 或先用「測試資料」確認系統本身正常 |
| 「行情資料過期」 | 網路卡頓或週期太小；等待下一根 K 線收盤後重新整理 |
| 一直是「觀望」 | **正常**：沒有優勢、市場狀態不適合、成本過高或證據不足時系統會觀望。可在「交易訊號」頁看具體原因 |
| 「依風險預算算得數量低於最小下單量」 | 資金太小或止損太遠；調高模擬初始權益（`.env`）或換較近的止損 |
| 回測 0 筆成交 | 看「被風控擋下的候選進場」彙總；通常是成本占比過高 |
| 想重置模擬帳戶 | 關閉程式，刪除 `data/aicq.db`（會一併刪除 K 線快取與紀錄） |

## 9. 仍然存在的已知風險（審查後）
- **策略沒有任何真實資料的樣本外證據**；合成資料上基準策略扣成本後幾乎不成交。預設參數是事前設定、未對任何資料調校。
- 止盈「觸價即成交」偏樂觀；K 線內價格先後順序無法還原（只能保守判定）；固定滑價與固定資金費率是假設。
- 強平價為逐倉粗估（不含分級維持保證金），真實下單前必須改用交易所公式。
- 紙上交易以最新收盤價＋固定滑價成交，沒有深度／部分成交；多商品持倉的未實現損益只以目前商品的最新價估值。

- CCXT 真連線、Streamlit／Plotly 實際渲染、pytest 本身、依賴版本相容性仍**未在本開發環境驗證**。
